# Seibi documentation

This directory holds the current guidance for Seibi: what it is, how to test
it, and what its current validation status is. It does not hold the full
historical evidence record; that lives under
[`../evidence/`](../evidence/).

- [`METHOD.md`](METHOD.md) — what Seibi does, when to use it, and its safety
  model.
- [`TESTING.md`](TESTING.md) — how Seibi is tested, and where to find raw
  evidence.
- [`VALIDATION.md`](VALIDATION.md) — the validation status of the current
  release.
- [`RELEASES.md`](RELEASES.md) — release history and how to read it.

Maintainer process documentation lives at the repository root:
[`RELEASE_SOP.md`](../RELEASE_SOP.md) and
[`RELEASE_CHECKLIST.md`](../RELEASE_CHECKLIST.md).
